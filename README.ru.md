# CheckProg

**Чек-лист для Windows: список с галочками, комментарий к каждому пункту, тёмная тема. Каждый список - отдельный файл `.json`.**

Простая программа-чек-лист для Windows 10 и 11. Впишите названия пунктов и отмечайте галочкой то, что уже сделано. Каждый список хранится в отдельном файле `.json`, так что можно держать разные списки: покупки, дела на неделю, вещи в поездку.

Есть два варианта:

| Вариант | Файл | Когда подходит |
|---|---|---|
| Portable | `CheckProg-<версия>-Portable.zip` | Без установки. Можно носить на флешке. |
| Установщик | `CheckProg-<версия>-Setup.exe` | Обычная установка с ярлыком в меню «Пуск». |

## Portable-версия

1. Распакуйте архив в любую папку, где у вас есть право записи. Подойдёт папка на рабочем столе или флешка. `C:\Program Files` не подойдёт: туда программа не сможет записать настройки.
2. В архиве папка `CheckProg`. Откройте её и запустите `CheckProg.exe`. Папку `_internal` рядом не трогайте: в ней библиотеки программы, без неё она не запустится.

Рядом с программой лежит файл `portable.flag`. Пока он на месте, программа хранит всё в своей папке: настройки в `settings.json`, а списки по умолчанию предлагает сохранять в папку `lists`. Если удалить `portable.flag`, программа будет вести себя как установленная.

## Установка

1. Запустите `CheckProg-<версия>-Setup.exe`.
2. Выберите, для кого ставить: только для вас (права администратора не нужны) или для всех пользователей.
3. По желанию отметьте «Создать значок на рабочем столе».

Удаление: «Параметры» → «Приложения» → CheckProg → «Удалить». Ваши списки при этом не удаляются. Файл настроек `%APPDATA%\CheckProg\settings.json` тоже остаётся, его можно удалить вручную.

## Как пользоваться

Окно состоит из четырёх частей: сверху прогресс («Выполнено: 2 из 5» и полоса), в середине список, под ним поле комментария, в самом низу поле для нового пункта.

- **Добавить пункт.** Введите текст в нижнее поле и нажмите Enter или «Добавить». Пустой текст не добавляется. Переносы строк и табуляция заменяются пробелами.
- **Отметить выполненное.** Щёлкните по квадратику ☐ слева от пункта или выделите строку и нажмите пробел. Выполненный пункт становится серым и зачёркнутым. Повторный щелчок снимает отметку.
- **Изменить текст.** Дважды щёлкните по тексту или нажмите F2. Enter сохраняет, Esc отменяет. Если стереть текст целиком, останется старый.
- **Удалить пункт.** Выделите его и нажмите Delete, либо щёлкните правой кнопкой и выберите «Удалить». Подтверждения нет. Если удалили по ошибке, закройте файл без сохранения.
- **Поменять порядок.** Перетащите строку мышью или нажмите Ctrl+↑ и Ctrl+↓.
- **Снять выделение.** Щёлкните по выделенной строке ещё раз, щёлкните по пустому месту под пунктами или нажмите Esc.
- **Комментарий к пункту.** Выделите пункт и пишите в поле «Комментарий к «…»:» под списком. Можно в несколько строк. Текст сохраняется в пункт сразу, отдельной кнопки нет. Чтобы убрать комментарий, сотрите текст целиком. Перейти в поле можно и через «Пункт» → «Комментарий».
- **Посмотреть комментарии прямо в списке.** У пунктов с комментарием справа стоит стрелка ▼. Щелчок по ней раскрывает комментарий под пунктом серым курсивом, стрелка становится ▲, повторный щелчок сворачивает. С клавиатуры: → раскрывает, ← сворачивает. «Вид» → «Развернуть все комментарии» раскрывает сразу все. Длинный комментарий переносится по ширине списка. Двойной щелчок по строке комментария переводит в поле комментария под списком. Раскрытость в файл не сохраняется.

Все действия с пунктами есть также в меню «Пункт» и в меню по правой кнопке мыши. Если навести мышь на свёрнутый пункт с комментарием, комментарий покажется во всплывающей подсказке. Краткая памятка по всем действиям: «Справка» → «Как пользоваться» (F1).

### Файлы

Программа работает как Блокнот. Меню «Файл»: «Создать», «Открыть», «Сохранить», «Сохранить как».

- Если есть несохранённые изменения, в заголовке окна перед именем файла стоит `*`.
- При закрытии окна, создании или открытии другого списка программа спросит, сохранить ли изменения.
- При следующем запуске откроется последний список, с которым вы работали.
- Файл можно открыть и так: перетащите его на `CheckProg.exe` или выберите «Открыть с помощью» → CheckProg.

### Тема

Меню «Вид»: «Тема как в системе», «Светлая тема» или «Тёмная тема». По умолчанию программа следует теме Windows («Параметры» → «Персонализация» → «Цвета» → «Режим приложения»). Если поменять её, пока программа открыта, программа переключится сама. Выбор запоминается.

Программа выглядит как приложения Windows 11: скруглённые меню, поля и кнопки. Тема действует на всё, в том числе на окна открытия и сохранения файла и на вопрос «Сохранить изменения?». На Windows 10 окно выглядит проще, но работает так же.

## Горячие клавиши

Сочетания работают и в русской, и в английской раскладке. Alt-сочетания привязаны к клавишам, на которых нарисованы буквы Ф, П, В и С.

| Клавиши | Действие |
|---|---|
| Ctrl+N | Новый список |
| Ctrl+O | Открыть список |
| Ctrl+S | Сохранить |
| Ctrl+Shift+S | Сохранить как |
| Enter (в нижнем поле) | Добавить пункт |
| Пробел | Отметить или снять отметку |
| F2 или двойной щелчок | Изменить текст |
| Delete | Удалить пункт |
| Ctrl+↑ / Ctrl+↓ | Переместить пункт выше или ниже |
| Esc (в списке) | Снять выделение |
| → / ← (в списке) | Раскрыть или свернуть комментарий пункта |
| Ctrl+C / Ctrl+V / Ctrl+X / Ctrl+A | Копировать, вставить, вырезать, выделить всё в полях ввода |
| Ctrl+Z / Ctrl+Y | Отменить и повторить правку комментария |
| F10 или Alt+Ф/П/В/С | Открыть меню |
| F1 | Как пользоваться |
| ↑ ↓ Enter, ← → , Esc (в открытом меню) | Выбрать пункт меню, перейти в соседнее меню или подменю, закрыть |
| Shift+F10 или клавиша контекстного меню | Меню действий с выделенным пунктом |
| Alt+F4 | Выход |

## Где хранятся данные

| | Portable | Установленная |
|---|---|---|
| Настройки (последний открытый файл, тема, размер и место окна) | `settings.json` рядом с `CheckProg.exe` | `%APPDATA%\CheckProg\settings.json` |
| Папка для списков по умолчанию | `lists` рядом с `CheckProg.exe` | `Документы\CheckProg` |

Окно открывается там и такого размера, где его закрыли, в том числе развёрнутым (с 2.1.0). Если того монитора больше нет или сохранённое испорчено, окно встаёт в размере по умолчанию.

Списки можно сохранять в любое место, папка по умолчанию только предлагается в диалоге. Какой режим сейчас работает и где лежат файлы, показано в «Справка» → «О программе».

## Формат файла

Обычный JSON в кодировке UTF-8. Его можно открыть и поправить в любом текстовом редакторе.

```json
{
  "version": 1,
  "items": [
    {"text": "Купить молоко", "done": false, "note": "2,5%, две бутылки"},
    {"text": "Позвонить в банк", "done": true}
  ]
}
```

- `text`: текст пункта, обязательное поле.
- `done`: `true` или `false`. Если поля нет, пункт считается невыполненным.
- `note`: комментарий, строка, переносы строк записываются как `\n`. Поле пишется только у пунктов с комментарием. Файлы версии 1.0 открываются без изменений.
- Пункты с пустым текстом при открытии пропускаются.

Программа сохраняет файл так, чтобы сбой во время записи (например, выключили питание) не испортил старую версию: сначала пишется временный файл, потом он заменяет старый.

## Частые вопросы

**Windows пишет «Система Windows защитила ваш компьютер».** Программа не подписана цифровой подписью. Нажмите «Подробнее» → «Выполнить в любом случае».

**Антивирус ругается на CheckProg.exe.** Программы, собранные PyInstaller, иногда вызывают ложные срабатывания. Можно собрать exe самостоятельно из исходников (см. ниже) или добавить файл в исключения.

**Зачем папка `_internal`?** В ней библиотеки Qt, на которых сделано окно. Программа хранит их рядом, а не распаковывает при каждом запуске, поэтому запускается быстро.

**«Не удалось открыть файл… ошибка JSON».** Файл повреждён или это не список CheckProg. Текущий список при этом остаётся открытым, ничего не теряется.

**Список не открылся при запуске.** Если последний файл переместили или удалили, программа молча начинает с пустого списка.

## Для разработчиков

Нужен Python 3.10 или новее (проверено на 3.13). Окно сделано на Qt (PySide6). Все зависимости ставятся в папку `.venv` внутри проекта, глобальный Python не трогается.

```bash
python -m venv .venv
.venv\Scripts\python -m pip install -r requirements-dev.txt
```

Запуск из исходников:

```bash
.venv\Scripts\python -m checkprog
```

Тесты (pytest и pytest-qt; окна при этом на экране не появляются):

```bash
.venv\Scripts\python -m pytest -q
```

Сборка portable-архива и установщика (Inno Setup 6 ставится отдельно). Скрипт сам создаст `.venv`, если его нет, поставит зависимости и прогонит тесты:

```bash
winget install JRSoftware.InnoSetup
powershell -ExecutionPolicy Bypass -File packaging\build.ps1
```

Результат появляется в папке `dist`: `CheckProg\` (готовая папка программы), `CheckProg-<версия>-Portable.zip` и `CheckProg-<версия>-Setup.exe`. Если Inno Setup не найден, скрипт соберёт только portable-архив.

Структура проекта:

```
checkprog/
  model.py      список пунктов, загрузка и сохранение (без Qt)
  settings.py   где хранить настройки: portable или установленная версия
  listmodel.py  модель Qt поверх списка: все изменения идут через неё
  delegate.py   отрисовка строки: квадратик, текст, стрелка, раскрытый комментарий
  window.py     главное окно: меню, список, панель комментария, файлы, клавиши
  theme.py      режим темы (как в системе, светлая, тёмная)
  app.py        запуск: QApplication, стиль windows11, русские тексты Qt
  icon.ico      иконка (создаётся packaging/make_icon.py)
tests/          тесты модели, делегата, окна и скорости ресайза
packaging/
  build.ps1     сборка
  installer.iss сценарий Inno Setup
  launcher.py   точка входа для PyInstaller
  make_icon.py  генерация иконки
docs/superpowers/  спецификации и планы разработки
```

Версия программы задаётся в `checkprog/__init__.py`. Сборка берёт её оттуда и подставляет в имена файлов и в установщик.

До версии 2.0 окно было на Tkinter. Его заменили на Qt, потому что Tk на Windows заметно тормозил при изменении размера окна (подробности в `docs/superpowers/specs/2026-09-19-resize-performance.md` и `2026-09-19-qt-port-design.md`).

## Скриншоты собираются программой

`tools/make_screenshots.py` создаёт временный список, открывает его в настоящем окне и снимает виджет через `QWidget.grab()` - в светлой и в тёмной теме. Снимок области экрана не годится: окно может оказаться позади других, и в кадр попадёт чужое содержимое. Настройки при этом берутся во временную папку, так что `settings.json` и «последний открытый файл» у автора не меняются.
