# CheckProg: тёмная тема

Дата: 2026-09-12. Дополнение к `2026-09-12-checkprog-design.md`.

## Поведение

- Меню «Вид → Тема»: «Как в системе» (по умолчанию), «Светлая», «Тёмная».
- Выбор сохраняется в `settings.json` (ключ `theme`) и применяется сразу, без перезапуска. Неизвестное значение в настройках считается «Как в системе».
- «Как в системе» читает `HKCU\Software\Microsoft\Windows\CurrentVersion\Themes\Personalize\AppsUseLightTheme` (0 означает тёмную). Тема перечитывается, когда окно получает фокус, так что смена темы Windows подхватывается без перезапуска. Если значение прочитать нельзя, выбирается светлая.

## Отрисовка

- Светлая: нативная ttk-тема `vista`, как раньше. Тёмная: ttk-тема `clam` с тёмной палитрой, потому что `vista` игнорирует цвета полей ввода.
- Настройки стиля (высота строки, раскладка элемента Treeview без индикатора) привязаны к ttk-теме, поэтому применяются заново после каждой смены.
- Картинки-галочки пересоздаются под палитру. Пустой квадрат в тёмной теме тёмный со светлой рамкой.
- Заголовок окна: `DwmSetWindowAttribute(DWMWA_USE_IMMERSIVE_DARK_MODE=20)`, при ошибке 19 (старые сборки Windows 10), затем `SetWindowPos(SWP_FRAMECHANGED)` для перерисовки. Если ни одна сборка это не поддерживает, вызов просто ничего не делает.
- Системная полоса меню Windows не перекрашивается, поэтому она заменена своей полосой из `tk.Menubutton` в обеих темах. Выпадающие и контекстное меню окрашиваются палитрой.
- Клавиатура: F10 открывает «Файл». Alt+Ф, Alt+П, Alt+В, Alt+С открывают меню, клавиша определяется по коду, как у Ctrl+S. Alt+F4 по-прежнему закрывает окно.
- Стандартные диалоги Windows (Открыть, Сохранить, вопросы) остаются системными.

## Инварианты для тестов

1. После смены темы строки списка совпадают с моделью, выделение и флаг изменений не меняются.
2. Высота строки и раскладка Treeview одинаковы после смен vista → clam → vista.
3. Многократное переключение не накапливает картинки (`image names` не растёт).
4. Все меню (полоса, выпадающие, подменю, контекстное) получают цвета текущей палитры.
5. Режим переживает перезапуск; мусор в настройках не ломает запуск.
6. «Как в системе» следует реестру при получении фокуса; явный режим реестр игнорирует.
7. Alt-клавиши без назначения (например, F4) не перехватываются.
