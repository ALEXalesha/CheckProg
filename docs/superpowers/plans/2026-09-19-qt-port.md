# CheckProg 2.0 (Qt) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the Tkinter UI of CheckProg with PySide6 (Qt Widgets) so the window resizes smoothly, keeping every 1.3.1 feature, the file format and the portable/installer builds.

**Architecture:** `ChecklistModel(QAbstractListModel)` wraps the unchanged `model.Checklist` and is the only writer after load. `ItemDelegate` paints one row per item (checkbox, text, ▼/▲, expanded note wrapped by Qt) and answers hit tests from the same layout function it paints with. `MainWindow` wires menus, the note panel, the add row, files and keys. Spec: `docs/superpowers/specs/2026-09-19-qt-port-design.md`.

**Tech Stack:** Python 3.13, PySide6-Essentials 6.11 in a project `.venv`, pytest + pytest-qt (offscreen), PyInstaller `--onedir`, Inno Setup 6.

**Conventions:** run everything through `.venv\Scripts\python.exe` (below: `$PY`). Commit as the identity configured in the repository (`git config user.name` / `user.email`). Tests set `QT_QPA_PLATFORM=offscreen` in `tests/conftest.py`.

### Task 3: ChecklistModel

**Files:** Create `checkprog/listmodel.py`, `tests/test_listmodel.py`.

```python
NoteRole = Qt.UserRole + 1
ExpandedRole = Qt.UserRole + 2
ItemRole = Qt.UserRole + 3               # the Item object itself

class ChecklistModel(QAbstractListModel):
    changed = Signal()                   # after every mutation (incl. reset)
    def __init__(self, checklist=None, parent=None)
    checklist: Checklist                 # property
    def set_checklist(self, cl)          # beginResetModel/endResetModel
    def rowCount(self, parent=QModelIndex()) -> int   # 0 for valid parent
    def data(self, index, role)          # Display/Edit=text, CheckState=Checked/Unchecked, NoteRole, ExpandedRole, ItemRole, ToolTip=note
    def setData(self, index, value, role)  # EditRole -> rename, CheckStateRole -> set_done
    def flags(self, index)               # Enabled|Selectable|Editable|DragEnabled|NeverHasChildren; invalid index -> DropEnabled
    def add(self, text) -> int|None
    def toggle(self, row)
    def rename(self, row, text) -> bool
    def set_note(self, row, text) -> bool
    def set_expanded(self, row, expanded) -> bool   # False if no note
    def expand_all(self, expanded) -> bool
    def remove(self, row)
    def move(self, src, dst) -> int      # beginMoveRows with Qt's dst+1 rule when moving down
    def supportedDropActions(self) -> MoveAction
    def mimeTypes / mimeData / dropMimeData   # internal row move only, "application/x-checkprog-row"
```

### Task 4: ItemDelegate

**Files:** Create `checkprog/delegate.py`, `tests/test_delegate.py`.

```python
class RowLayout(NamedTuple):
    check: QRect; text: QRect; arrow: QRect | None; note: QRect | None; note_lines: tuple[str, ...]

class ItemDelegate(QStyledItemDelegate):
    def layout(self, option, index) -> RowLayout   # single source for paint/sizeHint/hit
    def paint(self, painter, option, index)
    def sizeHint(self, option, index) -> QSize
    def hit(self, option, index, pos) -> "check"|"arrow"|"text"|"note"|None
    def wrap_note(self, note, width) -> tuple[str, ...]   # QTextLayout, WrapAtWordBoundaryOrAnywhere, cached by (note,width,font key)
    def createEditor / setEditorData / setModelData / updateEditorGeometry  # QLineEdit over layout.text
```
